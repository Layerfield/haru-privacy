01처음 시작하기

  1. 홈에서 ‘내 사진으로 시작’을 누르고 사용할 사진을 선택합니다. 또는 ‘샘플 사진 8장으로 체험’으로 시작합니다.
  2. 스타일과 비율을 선택하고, 각 페이지에서 사진이나 글을 눌러 편집합니다.
  3. ‘저장 전 확인’에서 배치와 글 넘침을 확인한 뒤 JPEG 또는 PNG를 만듭니다.
  4. 사진 보관함에 저장하거나 시스템 공유창에서 원하는 저장 위치·앱을 선택합니다.

지원 환경은 iOS·iPadOS 16 이상입니다. 기기와 운영체제에 따라 시스템 권한 화면의 표시가 다를 수 있습니다.

02자주 묻는 질문

사진 저장 권한을 거부했어요.

파일을 내보내고 시스템 공유창으로 파일 앱 등에 저장할 수 있습니다. 사진 보관함으로 저장하려면 기기 설정에서 Carousel Studio의 사진 추가 권한을 허용해 주세요.

사진이 불러와지지 않아요.

사진 앱에서 원본이 열리는지 확인해 주세요. iCloud에만 있는 사진은 시스템이 내려받을 때 네트워크가 필요할 수 있습니다. 손상되었거나 지원하지 않는 이미지 대신 다른 사진을 선택하고 저장 공간도 확인해 주세요.

사진이나 글이 잘려 보여요.

페이지에서 해당 요소를 선택해 사진 위치·확대 또는 글 내용을 조정해 주세요. ‘저장 전 확인’의 경고를 눌러 문제가 있는 요소로 이동할 수 있습니다.

다른 비율로 바꾸면 원본이 바뀌나요?

비율 변경은 새 프로젝트 복사본을 만듭니다. 기존 프로젝트는 홈의 ‘내 이야기’에서 다시 열 수 있습니다.

다른 기기에서 프로젝트를 볼 수 있나요?

현재 앱에는 계정 기반 동기화나 프로젝트 패키지 공유 기능이 없습니다. JPEG·PNG 결과물은 공유할 수 있지만 편집 가능한 프로젝트 원본을 옮기는 기능은 아닙니다.

프로젝트를 삭제하거나 복구하고 싶어요.

현재 프로젝트별 삭제 버튼은 없습니다. 전체 로컬 앱 데이터 삭제와 외부 저장 사본·백업은 데이터 관리와 삭제 안내를 확인해 주세요. 개발자가 기기의 프로젝트를 원격 복구할 수는 없습니다.

03문제를 알려주실 때

  • 앱 버전과 빌드 번호
  • 기기 모델과 iOS·iPadOS 버전
  • 문제가 발생한 단계, 기대한 결과와 실제 결과
  • 가능하다면 개인정보를 가린 화면 캡처

원본 사진, 비밀번호, 결제 정보, 민감한 개인정보를 보낼 필요는 없습니다. 문의 접수만으로 기기 안의 데이터에 접근할 수는 없습니다. 메일로 확인 후 답변드리며, 확정된 응답 시간이나 복구 성공을 보장하지는 않습니다.
