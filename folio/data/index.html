01삭제할 앱 계정은 없습니다

Carousel Studio에는 회원가입이나 서버 계정이 없습니다. 개발자 서버에 사진·프로젝트를 보관하지 않으므로 서버 계정 삭제를 신청하실 필요가 없습니다. 아래 절차는 현재 iPhone·iPad 앱에 적용됩니다.

02기기의 앱 데이터를 삭제하려면

  1. 남길 결과물이 있다면 먼저 JPEG·PNG로 내보내 주세요. 이 파일은 편집 가능한 프로젝트 원본을 복원하는 백업이 아닙니다.
  2. 기기의 설정 → 일반 → iPhone 저장 공간(iPad는 iPad 저장 공간)에서 Carousel Studio를 선택합니다.
  3. 앱 삭제를 선택합니다. 앱 정리하기는 문서와 데이터를 남기므로 전체 삭제가 아닙니다.

이렇게 하면 해당 기기에 보관한 프로젝트 문서, 작업용 사진, 복구본, 앱 안의 출력 파일이 제거됩니다. 현재 앱에는 프로젝트 하나만 삭제하거나 앱 안에서 전체 데이터를 초기화하는 기능이 없습니다.

03앱 밖의 사본과 백업도 확인해 주세요

  • 사진 앱: 저장한 결과물은 사진 앱에서 별도로 삭제하고, 필요하다면 ‘최근 삭제된 항목’도 확인합니다.
  • 파일 앱과 공유 대상: 내보낸 파일은 저장한 폴더 또는 전달한 서비스에서 직접 관리합니다.
  • 기기·iCloud·컴퓨터 백업: 기존 백업이 자동으로 제거되는 것은 아닙니다. Apple의 백업 관리 설정을 확인해 주세요. 백업을 복원하면 이전 앱 데이터가 다시 나타날 수 있습니다.

앱 삭제가 외부 사본까지 일괄 삭제하거나 모든 백업에서 복구 불가능하게 지우는 것은 아닙니다.

04문의 이메일의 개인정보 삭제 요청

지원 메일로 보낸 개인정보의 열람·정정·삭제를 요청하려면 salient-buckram.1r@icloud.com으로 연락해 주세요. 기존 문의를 찾을 수 있도록 사용했던 이메일 주소와 대략적인 문의 시점을 알려주세요. 요청을 확인하는 데 필요한 최소한의 정보만 요청합니다.

관련 법령에 따른 보관이 필요한 경우에는 해당 범위와 사유를 안내합니다. 개발자는 기기에만 저장된 프로젝트, 사용자의 iCloud 백업, 다른 공유 서비스의 사본을 원격으로 삭제할 수 없습니다.
