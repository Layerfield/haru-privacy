01앱에서 개발자에게 전송하는 데이터

Carousel Studio(번들 식별자 com.haru.folio)는 Donghyun Shin이 제공하는 사진·텍스트 캐러셀 편집 앱입니다. 현재 앱은 선택한 사진, 입력한 글, 프로젝트 또는 편집 이력을 개발자 서버로 수집하거나 전송하지 않습니다.

회원가입, 광고, 사용자 추적, 제3자 분석·충돌 수집 SDK를 사용하지 않습니다. 지원 이메일과 이 웹사이트의 처리 방식은 아래에서 별도로 설명합니다.

02기기에서 처리하고 보관하는 내용

  • 사용자가 선택한 사진의 작업용 사본, 입력한 글과 프로젝트 제목
  • 사진 참조, 위치·확대·필터·프레임·레이아웃 및 생성·수정 시각
  • 저장 문서, 복구용 직전 정상 문서와 생성한 JPEG·PNG 파일

편집과 이미지 생성은 기기에서 이루어지며, 이 파일은 앱의 로컬 저장 공간에 보관됩니다. 선택한 원본은 가져오는 동안 임시 파일로 복사될 수 있으며, 처리 후 임시 사본을 정리합니다. 가져온 사진은 방향을 보정하고 크기를 조정한 작업용 JPEG로 변환합니다. 원본의 EXIF·GPS 메타데이터는 작업본에 복사하지 않지만, 사진이나 글 자체에 보이는 개인정보까지 지우는 기능은 아닙니다.

03사진 선택과 저장 권한

사진 가져오기는 Apple의 시스템 사진 선택기를 사용합니다. 사용자가 선택한 이미지만 전달받으며 전체 사진 보관함 읽기 권한을 요청하지 않습니다. iCloud에 있는 사진을 선택하면 Apple의 시스템이 해당 파일을 내려받을 수 있습니다.

완성한 이미지를 사진 보관함에 저장할 때만 사진 추가 권한을 요청합니다. 거부해도 앱에서 편집하고 파일로 내보내 공유할 수 있습니다. 권한은 기기의 설정 앱에서 변경할 수 있습니다. 카메라·마이크·위치·연락처·추적 권한은 요청하지 않습니다.

04사용자가 선택하는 공유와 백업

시스템 공유창에서 사용자가 선택한 앱·서비스로 내보낸 파일이 전달될 수 있습니다. 공유 후에는 해당 서비스의 개인정보 처리방침과 보관 설정이 적용됩니다.

앱 자체의 계정 기반 클라우드 동기화는 없습니다. 다만 로컬 앱 데이터와 사진 사본은 기기 설정에 따라 iCloud 또는 컴퓨터 백업, iCloud 사진에 포함될 수 있습니다. 개발자는 이 개인 백업에 접근할 수 없으며, 백업 관리에는 Apple의 설정과 정책이 적용됩니다.

05보관 기간과 삭제 방법

프로젝트, 작업용 사진, 복구본과 성공적으로 생성한 출력 파일은 앱 저장 공간에서 자동 만료되지 않습니다. 현재 앱에는 프로젝트별 삭제나 전체 초기화 버튼이 없습니다.

기기 설정에서 앱 삭제를 선택하면 해당 기기의 로컬 앱 데이터가 제거됩니다. 앱 정리하기는 데이터가 남는 기능입니다. 사진 앱·파일 앱·공유 대상에 저장한 사본과 기존 백업은 각각 별도로 관리해야 합니다. 자세한 절차는 데이터 관리와 삭제 안내를 확인해 주세요.

06이메일로 문의할 때

문의자가 자발적으로 보내는 이메일 주소, 문의 내용 및 첨부 자료는 문의 확인·답변·문제 해결에 사용합니다. 지원에 필요하지 않은 사진, 비밀번호, 결제 정보나 다른 사람의 개인정보는 보내지 마세요. 메일 전송·보관은 사용자의 메일 제공자와 수신용 Apple iCloud Mail에서 처리될 수 있습니다.

문의 정보는 처리와 후속 응대에 필요한 범위에서 보관하며, 보관 목적이 끝나면 삭제합니다. 관련 법령에 따라 보관이 필요한 경우에는 그 범위에서만 보관합니다. 열람·정정·삭제 등 개인정보 관련 요청은 salient-buckram.1r@icloud.com으로 보내실 수 있습니다. 기기에만 있는 프로젝트는 개발자가 원격으로 조회하거나 삭제할 수 없습니다.

07이 안내 웹사이트

이 사이트에는 개발자가 설치한 광고·분석 도구, 쿠키 또는 입력 폼이 없습니다. 공개 페이지는 GitHub Pages가 제공합니다. 웹페이지를 열면 GitHub가 사이트 제공·보안 목적으로 IP 주소와 접속 정보 등을 처리할 수 있으며 GitHub 개인정보 처리방침이 적용됩니다.

이는 앱의 사진이나 프로젝트가 GitHub로 업로드된다는 뜻이 아닙니다. 사용자가 링크를 열거나 이메일을 보내는 경우에는 각 외부 제공자의 네트워크·처리 정책이 적용됩니다.

08아동의 정보와 방침 변경

앱은 생년월일이나 아동 계정을 요청하지 않으며 아동의 개인정보를 개발자에게 제출하도록 요구하지 않습니다. 아동의 정보가 문의 메일로 전달되었다고 생각하시면 아래 연락처로 알려주세요.

기능이나 데이터 처리 방식이 변경되면 이 페이지의 수정일과 내용을 갱신합니다. 별도 동의가 필요한 처리에는 해당 기능에서 필요한 안내와 동의를 제공합니다. 현재 방침은 위에 표시한 iOS·iPadOS 버전에 적용됩니다.
